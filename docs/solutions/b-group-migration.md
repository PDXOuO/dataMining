# 方案 B：专业画像分群迁移

> 分支：`solution/b-group-migration`
> 定位：冷启动（新人组）专用通路，验证通过后并入方案 C

## 1. 目标

674 名新人中有 610 人没有任何借阅历史，只能依靠画像推荐。本方案要在**零行为数据**的条件下，把新人组 HitRate@10 从官方学院热门基线的 0.073 提升到 0.10 以上。

老人组不在本方案范围内，沿用方案 A 的热门兜底——因此本分支单独提交时总分会偏低（老人组权重 60%），它的价值在于验证新人通路的有效性。

## 2. 核心依据

- **Deezer（Briand et al., RecSys 2021）**：冷启动用户即使已被映射到 warm 嵌入空间，系统仍不做最近邻，而是分配到约 1000 个 segment 后取段内热门——单用户预测向量噪声大，分群起正则化作用。效果 Precision@50 22.75% vs 热门基线 8.92%。
- **微信读书**：按性别/年龄/城市分群 + 群内热门书单，转化率较编辑推荐提升约 50%。
- **本题实测**：610 名无历史新人中 526 人有专业与年级字段；专业约 128 个，粒度远细于学院（约 20 个）。而学院到中图法类目已呈现强映射（文学院 I 类 70%、艺术学院 J 类 47.5%、外国语 H 类 43%、数计 TP 类 29%）。

结论：**分群粒度越细越好，但细粒度群体的样本量必须用平滑手段补救。**

## 3. 算法

### 3.1 三级回退与贝叶斯平滑

对每个「专业 g」，统计其索书号借阅分布 `P_g(item)`；学院分布 `P_dept(item)`；全局分布 `P_global(item)`。
样本量 `n_g` 为专业 g 的历史借阅条数，用线性插值平滑：

```
P_g*(item) = λ · P_g(item) + (1 − λ) · P_dept(item) + ε · P_global(item)
λ = n_g / (n_g + k)
```

- `k` 为平滑强度，初值取 20，按回测调整；
- `ε` 为全局底噪，取 0.05~0.1，保证长尾专业也有输出；
- 学院层同样对全局做一次平滑，形成递归。

这一步是本方案的核心。128 个专业中有相当一部分样本量不足 10 条，直接取专业热门会严重过拟合到个别读者。

### 3.2 列表构造：类目配额

新人组评分为 `0.5 × HitRate + 0.5 × Recall`，**没有 NDCG 项**，因此 10 个位置是 10 次独立押注，最优策略是最大化覆盖而非堆叠同类。但全局 I 类（文学）占 39%，完全放弃文学会丢失大量保底命中。

配额方案（初值，待回测）：

| 区段 | 位置 | 来源 | 目的 |
|---|---|---|---|
| 专业区 | 1–6 | 该专业相对全局**超额**的类目 Top 书 | 差异化，高杠杆 |
| 保底区 | 7–9 | 文学类（I）近期热门 | 保证基础命中 |
| 新书区 | 10 | 新书池中该专业类目的新入藏 | 吃时间窗口红利 |

「超额」指 `P_g(c) / P_global(c)` 最大的类目，而非绝对借阅量最大的类目——否则所有专业都会选出文学类。

### 3.3 新书池的使用

新书池 8297 册，处理日期覆盖 2025-01 至 2026-10。冷启动读者更可能借新到馆的书，按入藏时间分桶加权：

| 入藏时间 | 权重 |
|---|---|
| 2025-09 ~ 2026-03 | 1.0 |
| 2025-01 ~ 2025-08 | 0.7 |
| 2026-04 之后 | 0.3 |

过新的书（2026 年 4 月后入藏）在答案窗口内可能尚未被借，给低权重而非排除。分桶边界需用回测确定——但注意回测时必须使用切分点之前的数据构造该表，否则构成时间泄漏（Ji et al., TOIS 2023：泄漏会让 nDCG 虚高 21.7%~73.4%，且模型排名反转）。

### 3.4 画像字段的可用性与取舍

| 字段 | 可用人数 | 是否使用 | 理由 |
|---|---|---|---|
| 学院 | 674 / 674 | 是 | 覆盖率 100%，是回退的中间层 |
| 专业 | 526 / 610（无历史者中） | 是 | 区分度最高 |
| 年级 | 526 / 610 | 谨慎 | 大一与大四的阅读差异真实存在，但交叉后样本极少 |
| 性别 | 337 / 611 | 弱特征 | 对图书推荐增益存疑，仅作消融对照 |
| 办证日期 | 337 / 611 | 否 | 与借阅行为无稳定因果，且缺失率高 |
| 读者类别 | 674 / 674 | 是 | 教师与学生的借阅分布差异明显 |

## 4. 预期指标

| 变体 | 新人 HitRate@10 | 说明 |
|---|---|---|
| 学院热门（官方基线） | 0.073 | 锚点 |
| 专业热门（无平滑） | 0.07 ~ 0.09 | 长尾专业过拟合，可能反而不如学院 |
| 专业热门（k=20 平滑） | 0.10 ~ 0.13 | 目标 |
| 上述 + 新书池 | 0.12 ~ 0.16 | 预期最优 |

## 5. 实现要点与坑

1. **专业名需归一化**：验证集写法（「数字媒体艺术设计」「视觉传达设计」）与训练集「专业」字段的写法需对齐，存在「本科」后缀、全半角括号差异。
2. **学院字段同义写法**：「经管学院」vs「经济与管理学院」、「数计学院」vs「数学与计算机学院」，必须先建映射表。验证集的学院值已是规范形式，以它为基准映射训练集。
3. **专业样本量分布极偏**：需先统计每个专业的借阅条数分布，若中位数低于 20，则平滑系数 k 需上调。
4. **不要用验证集的「历史借阅册数」**：对无历史者是 0，对有历史者才是真实值，混用会造成逻辑分支错误。
5. **老人不可直接套用本方案**：老人要求推荐「未借过的书」，分群热门会大量命中其已借书，必须过滤。

## 6. 与主线的衔接

并入方案 C 时，本方案作为「新人通路」的整体实现：方案 C 的召回层为新人调用本模块，老人走共现通路；融合层的权重按用户类型切换。

需要注意：一旦并入 C，新人列表的配额需要与 C 的其他通路联合调优，本分支的配额参数（6/3/1）只是起点。
