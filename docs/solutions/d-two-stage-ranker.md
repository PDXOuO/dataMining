# 方案 D：多路召回 + GBDT 精排

> 分支：`solution/d-two-stage-ranker`
> 定位：方案 C 的增强项，非独立方案；成本最高、增益不确定

## 1. 目标

用 Kaggle OTTO / H&M 的两阶段范式替代方案 C 中的手工 RRF 融合：先由三路召回生成每用户约 100 个候选，再用 LightGBM 学习各信号的最优组合，取 Top-10。

预期相对方案 C 提升 10%~20%，但**前提是方案 C 已跑通且回测框架可靠**。

## 2. 为什么两阶段有效

方案 C 的 RRF 权重是手工设定的常数（老人 0.6/0.25/0.15 等），这些权重理论上应随用户历史长度、类目集中度、物品热度动态变化——手工调参只能找到一组全局最优，无法个性化。

Kaggle OTTO 冠军与 H&M 第 2 名均采用「co-visitation 召回 + GBDT 重排」，H&M 第 2 名在总结中明确深度学习与 embedding 在该任务上无效，而 LGBMRanker 配合丰富特征效果显著。这为本题提供了直接的工程先例。

## 3. 候选生成

沿用方案 C 的三路召回，**放宽候选数量、不做过早截断**：

| 通路 | 候选数/人 | 备注 |
|---|---|---|
| 物品共现 | 60 | 排除已借 |
| 内容相似 | 40 | 仅对历史项扩展，新书写入单独字段 |
| 分群热门 | 40 | 按专业平滑分布取 |
| 新书池专项 | 20 | 按入藏时间窗加权 |

合并去重后约 100~140 个候选/人。去重时必须保留「该候选来自哪几路」的标记，作为特征而非丢弃。

## 4. 特征设计

**召回侧（关键）**

- 三路各自的原始分与归一化排名；
- 命中通路数量（三路同时召回的物品通常更可信）；
- 共现证据强度：命中该书的读者历史中有几条与之共现。

**物品侧**

- 借阅频次（全期 / 近 6 个月 / 近 12 个月三档）；
- 中图法一级、二级类目；出版年（数值化）；复本量；
- 新书年龄（距切分点天数，非新书置 −1）。

**读者侧**

- 历史借阅册数、去重索书号数、历史跨度天数；
- 历史类目分布熵（反映兴趣集中度）；
- 学院、专业、年级、读者类别。

**交叉特征（增益最大）**

- 物品类目 ∈ 该读者历史 Top-3 类目；
- 物品责任者是否出现在该读者历史中（同一作者的续读）；
- `P_user(category) / P_group(category)`：该读者相对其专业群体的类目偏好偏移；
- 物品热度分位数 × 读者活跃度分位数。

## 5. 标签构造

这是本方案成败的关键。

1. 取全局切分点 `T`（2024-09-01），答案窗口 `[T, T+14 个月)`；
2. 对 `T` 时刻有历史或有画像的读者，用同一套召回逻辑生成候选；
3. 候选出现在答案窗口内该读者的借阅集合中 → 正样本（1），否则负样本（0）；
4. **负样本下采样**：正负比约 1:4，但**不可全随机**——须保留一部分「高热度但未借」的困难负例，否则模型学不到区分度；
5. 训练集只用 `T` 之前的信息构造特征，答案窗口信息只用于打标签。任何在特征里使用 `T` 之后数据的做法都会导致泄漏，使回测指标虚高、线上崩盘。

## 6. 模型与训练

- **LightGBM LambdaRank**（`objective='lambdarank'`，`eval_at=[10]`），按读者分组；
- 或退化为二分类 `binary` + 分数排序，实现更简单、调试更快，先跑通再换 LambdaRank；
- 早停用验证切分（2024-03-01 训练 / 2024-09-01 验证），避免用最终答案调参。

## 7. 预期指标

| 阶段 | 老人 NDCG@10 | 老人 HitRate | 总分 |
|---|---|---|---|
| 方案 C | 0.06 ~ 0.10 | 0.12 ~ 0.18 | 12 ~ 16 |
| 方案 D（目标） | 0.09 ~ 0.13 | 0.14 ~ 0.20 | 15 ~ 20 |

## 8. 风险与失败模式

| 风险 | 说明 | 应对 |
|---|---|---|
| 候选质量决定上限 | 精排无法召回未进入候选的好书 | 先把召回候选数放宽到 100+，再谈排序 |
| 样本量不足 | 956 人 × 100 候选 ≈ 9.6 万行，但正样本仅数千 | 用回测切分扩充训练读者，不只用验证集 956 人 |
| 过拟合切分方式 | 单一 `T` 上训练+验证，结论可能不迁移 | 双切分点交叉验证 |
| 特征穿越 | 最容易犯的错：用答案窗口的热度做特征 | 特征构造统一走「`T` 之前切片」函数，禁止直接读全量 |
| 收益不抵成本 | 可能只提升 5%，却花掉 10 小时 | 设定止损：若首轮实验相对 C 提升 < 5%，立即放弃 |

## 9. 前置条件与止损线

**启动条件**（三者全部满足才开工）：

1. 方案 C 已产出可提交的 `result.csv` 且回测总分 ≥ 12；
2. 回测框架已验证无时间泄漏（用「打乱未来数据后指标应下降」做自检）；
3. 距离截止时间 ≥ 8 小时。

**止损线**：首轮实验若相对方案 C 的提升低于 5%，或训练/验证指标差距超过 30%（过拟合信号），立即停止，回归方案 C。

## 10. 与主线的衔接

本方案不独立成立，必须建立在方案 C 之上。若成功，合入 `main` 时保留方案 C 作为 fallback（通过开关切换），以确保最终提交物在任何情况下都能产出结果。
