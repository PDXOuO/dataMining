# 面向匿名冷启动与数据退化的图书馆图书推荐

**摘要**　本报告为第五届数据挖掘竞赛 C 题决赛方案。与初赛相比，决赛有两处结构性变化：答案不再公开，模型必须泛化而不能对着答案调参；模型还要在「读者画像被抹除 30%」与「借阅历史被截断」两种退化输入上再跑一遍，稳定性计入 14% 的总分。我们沿用初赛验证过的「院校—类目分层贝叶斯」主干，并针对决赛新增三件事：其一，把群体层从单一的学院细化到「学院 × 专业」，用贝叶斯收缩在两级之间自适应切换；其二，把群体底座从单一训练集扩展为「训练集 + 决赛输入历史」，解决训练集止于 2025 年 1 月、与答案窗口相隔 20 个月的时间断层；其三，为画像缺失设计学院→专业→全局的逐级回退，为历史缺失设计「只依赖类目而非顺序」的打分路径。

离线我们用三套互补口径评估：初赛四折时间切分（有真实答案，用于结构选择，均值 **8.40**）、决赛历史留出（最贴近决赛分布，n=109，7.77）、以及扰动实测（四折上施加与决赛同构的两种退化，**8.06 → 7.01 / 7.77**，据此估算鲁棒分 R≈0.49）。四份提交文件在同一套代码、同一组参数下生成，无随机过程，从解压到产出约 20 秒，输出与提交件逐字节一致。

**关键词**：推荐系统；冷启动；分层贝叶斯估计；鲁棒性；数据退化；图书馆借阅数据

## 1 任务与约束

### 1.1 决赛任务

决赛要求为四个榜单各提交一份推荐列表：公开榜 545 名读者、隐藏榜 575 名读者，以及隐藏榜同批读者的两份退化输入（扰动 A：30% 读者画像被抹为「未知」；扰动 B：部分读者历史被截断并打乱）。每份提交为两列 CSV，每人最多 10 个索书号，按置信度降序，白名单外不计分，漏交按 0 命中计。

评分与初赛完全一致：新人组 0.5×Hit@10 + 0.5×Recall@10，老人组 0.4×Hit@10 + 0.3×Recall@10 + 0.3×NDCG@10，单榜得分 =（0.4×新人 + 0.6×老人）×100。总分 = 0.30×公开榜 + 0.56×隐藏榜 + 14×R，其中 R = min(1, (扰动A + 扰动B)/2 ÷ 15)。

| 维度 | 初赛 | 决赛 | 本方案对策 |
|---|---|---|---|
| 答案 | 公开，可回测调参 | 不公开 | 用三套离线口径替代，禁止单口径决策 |
| 输入规模 | 956 人 | 545 / 575 / 575 / 575 | 四份共用同一代码路径 |

| 历史完整性 | 完整 | 58 人截断至 30%–70% 并打乱 | 打分只依赖类目集合，不依赖顺序 |
| 候选集 | 全馆 | 白名单（公开 21 536 / 隐藏 22 150） | 候选与计数同时限定在白名单内 |
| 新入藏 | 需自行识别 | 白名单已标记「是否新入藏」 | 独立一路赋分并限制配额 |

### 1.2 三个不变的结构性约束

1. **读者不可对齐**。决赛输入同样只有匿名 ID、画像与历史，没有行为明细；群体信号只能来自初赛训练集（29 841 条，止于 2025-01-16）与决赛输入自身的历史，用户级协同过滤与序列模型依旧不可行。
2. **答案已剔除历史书目**。老人组的答案不含其借过的书，复推等于 0 命中。这一条在实现上比听起来更容易出错，见 3.4 节记录的陷阱。
3. **数据规模不支持参数化模型**。群体底座合计覆盖白名单约 60.9%，其余 39% 的书没有任何计数，只能靠类目结构赋值。

### 2.2 三个决定设计方向的分布事实

**新人接近一半，且历史全空。** 隐藏榜 288 人（50.1%）为新人，历史字段完全为空。这批读者只能靠画像做群体迁移，也因此在扰动 A 下最脆弱。

**老人历史比预期短得多。** 隐藏榜老人历史册数的中位数只有 3 本，均值 12.9，最长 574 本。这意味着「按历史精确刻画兴趣」对多数老人并不成立，个体侧调整必须是温和的乘性提权，而不是按历史分布重排。

**新入藏占比高但几乎没有行为。** 白名单 33.3% 是新入藏，其中仅 4.3% 有任何借阅记录；而新入藏在隐藏榜答案中约占 15.9%。这一类书既不能靠计数打分，又不能忽略，必须单独赋分。

## 3 方法

### 3.1 总体框架

对读者 u，最终得分由群体项、个体项与新书项组合而成，已读书目一律置为 -1：

> s_u(i) = max( base_g(i) × boost_hist(i) , new_g(i) ) (1)

其中 base_g 为群体层得分（学院或学院×专业），boost_hist 为个体侧类目提权，new_g 为新入藏赋分。排序后按「新书每单至多 2 本」的配额取前 10。

### 3.2 群体底座：训练集与输入历史

决赛的群体信号有两个来源：初赛训练集（量大但旧）与决赛输入历史（新但只有 575 人）。我们把两者叠加计数：

> c_g(i) = c_train(i) + w · c_input(i) (2)

w 取 3。这个值不是拍定的：我们把训练集切成「12 个月前底座 + 近端 12 个月」模拟决赛的时间结构，w 从 0 扫到 8，w=1.0 在该模拟中最优（7.55），w=4 与 w=8 分别掉到 6.4 与 5.9，说明新数据的价值存在但会被过量加权淹没。决赛实际采用 3 而非 1，是因为决赛的历史窗口（2025-09 起）比模拟更贴近答案窗口，且自监督留出验证中 w=3 优于 w=1 与 w=8。

### 3.3 学院 × 专业的两级贝叶斯

学院层沿用初赛的分层收缩：以「学院在各类目上的占比 × 该类目内全局份额」作为先验，与学院原始计数按 λ 收缩。

> prior_d(i) = share_d( c2(i) ) × c_g(i) / Σ_{ j ∈ c2(i) } c_g(j) (3)

> s_d(i) = ( c_d(i) + λ · n_d · prior_d(i) ) / ( n_d · (1 + λ) ) (4)

λ 取 1.5。在此基础上，专业层（学院 × 专业）向学院层收缩，收缩强度 λ_m = 1.5，且专业样本少于 100 条时直接回退学院层：

> s_g(i) = ( c_g(i) + λ_m · n_g · s_d(i) ) / ( n_g · (1 + λ_m) ) (5)

这一层的收益是本次最大的单项改动：四折均值 7.93 → 8.40（+0.47）。它的作用机制不是「更细就更好」，而是**在样本足够时提供分辨力、样本不足时自动退回稳健层级**——同学院热门只有 1.63 这一事实正说明硬分组会被噪声吞掉。

### 3.4 个体侧调整与一个实现陷阱

老人组对其历史覆盖过的二级类目做乘性提权，提权强度按该类目在历史中的相对频次缩放：

> boost(i) = 1 + k · cnt( c2(i) ) / max_{c2} cnt( c2 ) (6)

k 取 1.6。随后把历史中已出现的书置为 -1，保证不复推。

这里有一个值得记录的实现陷阱：新入藏赋分（3.5 节）以 `max(base, new)` 的方式抬升新书分数，而**「新入藏且已被该读者借过」的书，其 -1 标记会被这步抬回正值**。这类书在扰动 B 下尤其容易浮出水面——历史被截断后，其余候选变少，被抬回的那本恰好进入前 10。我们在自查中发现扰动 B 有 1 名读者被复推，定位后在新书赋分之后**二次压制已读**，并在热度兜底补位时同样排除已读。修复后四份提交的复推读者数均为 0。这个 bug 不会影响分数上限，但正是手册第 2 条「按历史借过的书推荐等于 0 命中」所警告的那类错误。

### 3.5 新入藏：无行为时的结构化赋值

新入藏没有任何计数，但并非没有任何结构：它们有分类号。我们把新书的分数设为**同二级类目内有记录图书在群体得分上的分位数**（取 70 分位），并按二级类目批量计算。配额上限为每份列表 2 本。

配额不是可有可无的常数：初赛回测中，把配额放开会让列表被新书挤占，而这些书恰恰缺乏行为证据；把配额收紧到 0 则完全放弃 15.9% 的答案。2 本是在「覆盖新书答案」与「保住头部命中」之间的平衡点。

### 3.6 退化输入的降级路径

**画像缺失（扰动 A）**：学院缺失时退到专业，专业缺失时退到全局份额。实测扰动 A 中 173 名读者（30.1%）的学院、专业、年级、性别被抹为未知，但**读者类别与办证日期被保留**——这为下一代改进留下了入口（第 8 节）。

**历史缺失（扰动 B）**：打分只依赖历史的类目集合与频次，不依赖顺序；历史被截断只减少类目证据，不会让模型失稳。实测该退化仅掉 0.29 分。

## 4 离线验证体系

决赛没有答案，单一离线口径很容易把我们引向过拟合。我们用三套口径交叉验证，任何改动必须在至少两套上不退化才采纳。

<!--cap: 表 5　三套离线口径的定位-->
| 口径 | 构造方式 | 样本 | 用途 | 本方案成绩 |
|---|---|---|---|---|
| 初赛四折 | 四个时间切分点，候选池截止到切分点 | 500–1200 人/折 | 结构选择的主依据 | 8.40 |
| 决赛历史留出 | 取老人后半段历史为答案 | 109 人 | 最贴近决赛分布，仅看方向 | 7.77 |
| 扰动实测 | 四折上施加 30% 画像抹除 / 10% 历史截断 | 同上 | 估算鲁棒分 | 7.01 / 7.77 |

### 4.1 初赛四折

<!--cap: 表 6　四折逐折结果（新人为新人口径得分，老人为老人口径得分）-->
| 切分点 | 总分 | 新人组 | 老人组 | 新人/老人人数 |
|---|---|---|---|---|
| 2023-09-01 | 7.44 | 7.22 | 7.59 | 1167 / 584 |
| 2024-03-01 | 8.91 | 11.97 | 6.86 | 860 / 529 |
| 2024-06-01 | 8.84 | 12.37 | 6.48 | 631 / 346 |
| 2024-09-01 | 8.39 | 11.37 | 6.41 | 524 / 289 |
| 均值 | **8.40** | 10.73 | 6.84 | — |

首折明显偏低（7.44），原因是 2023-09 的切分点使候选池偏小、答案窗口跨越学期边界；我们在结构比较时统一用四折均值，避免被单折波动误导。

### 4.2 决赛历史留出

把隐藏榜老人历史的后 30% 作为答案、前 70% 作为输入，构造 109 个「准决赛」样本。该口径的分布最接近真实任务（同样的画像字段、同样的白名单、同样的历史长度分布），但样本小、答案稀疏，只用于判断改动方向是否一致。本方案 7.77，与四折结论方向一致。

### 4.3 扰动实测

把决赛的两种退化按相同比例施加到四折输入上：随机 30% 读者画像置为未知；随机 10% 有历史读者把历史截断到 30%–70% 并打乱。结果见第 7 节。

## 5 消融与否定路径

<!--cap: 表 7　主要结构项的消融（初赛四折均值）-->
| 变体 | 四折均值 | 变化 | 结论 |
|---|---|---|---|
| 完整模型 | 8.40 | — | 定稿 |
| 去掉专业层（仅学院） | 7.93 | -0.47 | 专业层有效，采纳 |
| 去掉历史提权（k=0） | 8.22 | -0.18 | 有效但幅度小 |
| 提权 k=1.0 | 8.46 | +0.06 | 与 1.6 同级，噪声范围内 |
| 收缩 λ=0.5 | 8.43 | +0.03 | 平坦，保持 1.5 |
| 新书配额 = 0 | 8.40 | 0.00 | 见下方说明 |

最后一行需要解释：在初赛四折的候选池里，「新书」被定义为切分点前从未被借过的书，其赋分低于头部候选，因此开不开配额对前 10 没有影响——**四折无法评估新书配额**。决赛白名单提供了官方的「是否新入藏」标记，我们据此确认新书确实进入列表（占比 14.0%–16.2%，每行不超过 2 本），配额的作用只能靠公开榜分数最终验证。

被否定的路径（均实现并回测，不做二次尝试）：

- **物品共现**：老人组 Hit 从 0.0450 掉到 0.0138，噪声主导；
- **历史时间衰减**：新书入藏日期不可信（65% 落在 2025Q4，但其中不少在 2025-08 前已有借出记录），衰减反而引入错误权重；
- **标题内容召回**：决赛新入藏 7 386 本中 **94% 没有题名**，只有索书号，内容匹配在决赛上物理不可行；
- **类目配额限制多样性**：初赛回测有害，已关闭；
- **专业粒度硬分组（不收缩）**：小样本学院崩到基线以下，必须收缩；
- **GBDT 精排**：特征维度不足、样本不足，交叉验证后不如直接打分。

## 6 鲁棒性分析

<!--cap: 表 8　扰动实测结果（四折均值，括号内为相对原始的变化）-->
| 条件 | 总分 | 新人组 | 老人组 |
|---|---|---|---|
| 原始输入 | 8.06 | 10.77 | 6.26 |
| 扰动 A（30% 画像缺失） | 7.01（-1.05） | 8.78（-2.00） | 5.83（-0.43） |
| 扰动 B（10% 历史截断） | 7.77（-0.29） | — | — |

两个结论：

**其一，历史截断几乎无害。** 掉 0.29 分，因为打分只依赖类目集合与频次，顺序信息本来就没被使用。这与手册 Q3 的意图一致：模型应当利用历史，但不应该依赖精确的序列位置。

**其二，画像缺失是主要失分点，且损失几乎全在新人组。** 新人组掉 2.00 分，老人组只掉 0.43。原因清楚：老人有历史，类目提权那条路径仍在工作；新人一旦画像被抹，就只能退到全局份额，推荐立刻退化为「全局热门」——而全局热门基线只有 5.15 分。

按 R = min(1, 7.39/15) ≈ 0.49 估算，鲁棒项只能拿到约 6.9/14 分。若公开榜与隐藏榜都与四折同水平（8.1），预计总分约 13.8。**这意味着：绝对分数的提升对鲁棒项的边际收益远大于「保稳」。** 任何在主榜上 +1 分的改动，同时也在扰动条件下 +1 分。

## 7 工程实现与复现

### 7.1 实现要点

- 候选集与所有计数同时限定在白名单内，避免推荐白名单外的书；
- 新书分位数原实现按「学院 × 类目」逐次调用分位数（约 15 万次），拟合需 21 秒；改为按类目预分组、学院成列一次排序后，拟合降到 0.4 秒，四份提交合计约 20 秒；
- 全流程无随机过程，同环境重复运行输出逐字节一致；
- 参数默认值即提交所用值，不传任何参数即可复现提交文件（这一点单独列入复现检查，因为默认值与提交值脱节是复现审查最常见的失败原因）。

### 7.2 复现步骤

```bash
pip install -r requirements.txt
python run.py --final
```

输出的四份 CSV 与提交文件 MD5 一致。环境：Python 3.10+，8 核 16 GB，无 GPU；三份提交合计用时远低于手册规定的 40 分钟 / 2 小时上限。

### 7.3 合规

仅使用组委会发放的数据（初赛训练集、决赛四份输入、两份白名单、学院映射表），未接入任何外部数据、预训练词向量或图书元数据；未尝试还原读者身份；代码、文档与文件名中不含队伍与学校信息。

## 8 防错清单与改进方向

决赛手册列出七条最常见的失败模式。我们逐条自查，结果如下。

| 易错项 | 自查证据 | 结论 |
|---|---|---|
| 只交热门榜 | 545 人推荐涉及 505 本不同图书，最热一本仅覆盖 56.9% 读者 | 未踩 |
| 复推历史借过的书 | 四份提交与该读者输入历史的交集均为 0（修复前扰动 B 有 1 人） | 已修 |
| 假设画像完整 | 扰动 A 下 7.01，较原始掉 1.05，仍有非零成绩 | 有兜底 |
| 假设历史完整 | 扰动 B 下 7.77，仅掉 0.29 | 未踩 |
| 新人不做冷启动 | 新人组四折 10.73，高于全局热门基线 | 未踩 |
| 忽略新入藏 | 新书占列表 14.0%–16.2%，每行上限 2 本 | 已覆盖 |
| 不写可复现代码 | 解压后 20 秒复现，MD5 与提交件一致 | 已满足 |

改进方向按预期收益排序：

1. **画像缺失时的粗粒度回退**。扰动 A 暴露出画像抹除后直接退到全局的问题；而实测显示「读者类别」（学生 / 教师 / 校外人员 / 离退休）与办证日期在扰动中**被保留**。用「读者类别 × 办证年份」作为学院之下的又一层回退，可能把新人组的 2.00 分损失收回一部分。
2. **历史长度的显式利用**。扰动 B 中「历史借阅册数」字段有时未被同步修改，可作为历史被截断的信号，从而对受影响读者采用更保守的打分。
3. **专业层收缩强度的分学院自适应**。当前 λ_m 全局统一，而各专业样本量差异极大（从个位数到数百条），按样本量自适应可能优于固定值。

## 9 结论

我们把决赛问题拆成三件事：群体信号怎么来、个体信号怎么用、信号缺失时怎么退。第一件用「训练集 + 输入历史」的双源底座与「学院 × 专业」两级收缩解决，四折 8.40；第二件用类目频次提权，幅度小但方向稳定；第三件用逐级回退与顺序无关的打分，使历史截断几乎无害、画像缺失仍保有 7.01 分。

需要强调的是我们对结论强度的判断：8.40 是初赛四折上的数字，与决赛分布存在系统性差异（决赛答案更个体化、白名单限定候选、新入藏占比更高），因此**它只能用于比较方案的相对优劣，不能当作决赛分数的预期**。真正的校准要等公开榜反馈；我们已把三套离线脚本与参数锁定机制准备好，任何一版改动都能在 20 秒内重新产出四份提交并逐份自查。
