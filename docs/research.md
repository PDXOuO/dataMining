# 调研报告：规则解读、文献依据与方案取舍

> 本文是技术报告（占评分 40 分）的论证底稿，也是各分支方案的设计依据。
> 撰写时间：2026-11-07

## 一、赛题本质：这是一道「强约束下的冷启动 + 稀疏召回」题

先看清评分函数在优化什么，再谈模型选型。总分结构为：

```
总分 = (0.4 × 新人组 + 0.6 × 老人组) × 100
新人组 = 0.5 × HitRate@10 + 0.5 × Recall@10
老人组 = 0.4 × HitRate@10 + 0.3 × Recall@10 + 0.3 × NDCG@10
```

三条推论直接决定策略：

1. **HitRate 是唯一稳定可控的抓手。** Recall 的分母是每人的答案集合大小 `|A|`，而 956 名读者在 14 个月窗口内（2025-09-01 ~ 2026-10-29）的真实借阅量我们无从得知。若 `|A|` 均值约 5，命中 1 本的 Recall 只有 0.2；命中 2 本才 0.4。这意味着 Recall 天然被压缩在低位，而 HitRate∈{0,1} 无此稀释。
2. **新人组不评 NDCG，因此「把最可能的一本放第一」对新人没有额外收益。** 10 个位置对新人来说是 10 次独立的「押注」，最优策略是**最大化覆盖不同方向**，而不是堆叠同类高分项。
3. **老人组 30% 是 NDCG，因此老人列表前 3 位必须放最高置信项。** 两个群体应使用不同的列表构造逻辑，而不是一套权重套到底。

官方给出的基线也印证了本题难度：全局热门 Top10 在验证集上新人 HitRate 0.040、同学院热门 0.073；换算总分约 3.3 分和 4.3 分。**分数天花板低是本题的结构性特征**，每一档 HitRate 提升都对应可观的名次差异。

## 二、数据画像（实测，非估计）

| 维度 | 事实 | 对方案的含义 |
|---|---|---|
| 规模 | 29857 条 / 5112 人 / 13525 索书号 | 稀疏度约 99.96%，比 MovieLens-100K 还小 3 倍 |
| ID 体系 | 验证集 `R0001` 匿名，训练集原始条码 | **无法 join**，用户级协同过滤/序列建模不成立 |
| 新人画像 | 610 人无历史，其中 **526 人有专业与年级**，337 人有性别与办证日期 | 冷启动可细到**专业级（约 128 个专业）**，而非只能到学院级 |
| 老人画像 | 281 人有历史，借阅册数中位数仅 4（均值 19 被 832 的长尾拉高） | 一半老人接近半冷启动，不能假设历史丰富 |
| 学院→类目 | 文学院 I 类 70%、艺术学院 J 类 47.5%、外国语 H 类 43%、数计 TP 类 29%（全局 TP 仅 6.3%） | 学院/专业到中图法类目存在强映射 |
| 全局类目 | I 类（文学）占 39% | 文学只能做**保底项**，差异化必须靠专业类目 |
| 近期热度 | 956 人历史列表合计 4039 条 / 3340 个去重索书号 | 这是「2025 上半年借阅快照」，比 2022–2024 全局热度更贴近答案窗口 |
| 新书池 | 8297 册，处理日期 2025-01 ~ 2026-10 | 可做冷启动召回源，但需按入藏时间分桶，过新的书风险高 |

**最关键的一条：验证集自带的「历史借阅索书号列表」是公开可用的真实输入，且时间上紧邻答案窗口。** 它同时承担三个作用——老人的行为序列、全校的近期热度统计、以及跨读者的共现来源。

## 三、文献综述与适用性判断

### 3.1 结论一：本赛规模下，复杂神经模型大概率是负资产

Dacrema 等人（TOIS 2021，《A Troubling Analysis of Reproducibility and Progress》）复现了 2015–2018 年顶会的 18 个神经 top-N 推荐方法，其中 12 个可复现的方法里，**11 个被精心调参后的 ItemKNN / 线性模型击败**，且模型排名对切分方式高度敏感。本题数据量比该文使用的 MovieLens-100K 更小，SASRec/BPR 无法获得足够训练信号。

工业侧的交叉印证：Kaggle OTTO 冠军与 H&M 第 2 名的方案均为「co-visitation matrix 生成候选 + LightGBM/CatBoost 精排」，H&M 第 2 名在总结中明确写道 *"Deep learning models and product embeddings did not work well"*。

**判断：不采用端到端深度模型。若后续要用神经方法，只用于特征生成（如 item2vec 向量作为共现补充），不承担主排序职责。**

### 3.2 结论二：冷启动的正确姿势是「分群 + 群内热门」，不是「映射到向量空间找最近邻」

Deezer 的落地论文（Briand et al., RecSys 2021）做了关键对照：即便已用神经网络把冷用户属性映射到 warm 用户嵌入空间，系统**仍然不直接做最近邻检索，而是聚类成约 1000 个 segment，再取段内最热门曲目**。作者的解释是单用户预测向量噪声过大，聚类相当于正则化。效果为 Precision@50 22.75%，热门基线 8.92%。

微信读书的实践更朴素：按性别/年龄/城市分群 + 群内热门书单，转化率较编辑推荐提升约 50%。

聚类-流行度方向的学术工作（ClusterPopRec 等）同样显示：按人口属性聚类用户 + 簇内流行度打分，在极端冷启动下相对 ItemKNN 有显著提升。

**判断：新人组的核心是「专业 → 学院 → 全局」三级回退的群体偏好，而非用户向量相似度。**

### 3.3 结论三：图书馆场景的既有实证不可直接照搬

- 河海大学等实证认为 ItemCF 在图书推荐中准确率最高、UserCF 覆盖率最高——但其前提是存在完整用户 ID 体系。本题只能使用**物品侧**共现。
- 山东大学（2024）提出按借阅频次分层的混合策略：高频书走「协同 + 内容」融合，借阅次数 ≤1 的书走预训练语言模型的内容推荐——这为「新书池只能用内容特征」提供了直接依据。
- 筑波大学在 33 名学生的极小样本上发现：CF 评价最差，关联规则次之，Amazon 式推荐最好。**这说明小样本下算法排名会反转**，不能盲信「CF 最优」的普遍结论。

### 3.4 结论四：离线验证必须严格按全局时间轴切分

Ji 等人（TOIS 2023）证明，忽略全局时间轴会让模型「推荐未来才入藏的书」，nDCG@10 虚高 21.7%–73.4%，且**模型相对排名会随泄漏量反转**。本题的新书池恰好覆盖 2025-01 至 2026-10，若回测时把切分点之后入藏的书当作候选，指标会系统性虚高。

**判断：回测严格采用单一全局切分点，候选池只保留切分点之前已入藏的索书号，近期热度也只统计切分点之前的数据。**

## 四、被排除的方案及理由

| 方案 | 排除理由 |
|---|---|
| UserCF / BPR / ALS / LightGCN | 验证集与训练集用户 ID 不可对齐，不存在共享用户，模型无法把训练集学到的用户向量用于 956 名目标读者；强行训练等于对每人独立做统计 |
| SASRec / GRU4Rec | 同上（需用户级序列），且 29857 条样本不足以训练 Transformer 类序列模型 |
| 元学习（MeLU）/ 跨域迁移 | 需要源域与目标域有重叠用户或可对齐的 warm 用户，本题两者皆无 |
| 纯 LLM 排序 | 推理成本高、无法批量覆盖 956 人、且缺乏可复现性保障；LLM 仅可作为内容语义向量的离线工具 |
| 多样性 / 长尾优化 | 初赛验证集评分**不含**多样性项（决赛才有），任何多样性惩罚都直接压低 HitRate，是纯亏损 |

## 五、方案设计与取舍

主线为**三路召回 + 规则融合**，按用户类型切换权重。

| 通路 | 适用群体 | 信号来源 | 作用 |
|---|---|---|---|
| 物品共现（item-item） | 老人为主 | 训练集 5112 人 + 956 人历史合并构图，带时间衰减与热门惩罚 | 兴趣延展，NDCG 主力 |
| 内容相似 | 老人 + 新人 | 中图法类目、责任者、题名字符 n-gram | 新书与长尾覆盖 |
| 分群热门 | 新人 + 老人兜底 | 专业 → 学院 → 全局三级回退，近期热度优先 | 冷启动主通路 |
| 新书池注入 | 全部 | 新书池按入藏时间分桶加权 | 借阅窗口内的新鲜度红利 |

融合采用加权 RRF（Reciprocal Rank Fusion）。选择 RRF 而非学习型融合的理由：956 名读者没有任何标注答案，无法训练融合权重；RRF 只依赖排名，对分数量纲不敏感，参数少、过拟合风险低。

三条明确的取舍：

1. **放弃模型新意，换取 HitRate 与可复现性。** 60 分是量化指标，40 分是报告；报告分靠结构完整、逻辑清晰、消融严谨，不靠模型先进性。而「无法复现直接取消资格」是资格线。简单方法的期望收益更高。
2. **新人列表以「覆盖」为目标，老人列表以「排序」为目标。** 由 3.1 节的推论 2、3 决定。
3. **时间近邻优先于长期稳定偏好。** 956 人历史列表代表的 2025 上半年热度，与答案窗口（2025-09 起）紧邻，其权重应高于 2022–2024 的全局统计。

## 六、风险与未知

| 风险 | 影响 | 应对 |
|---|---|---|
| 答案集合大小 `|A|` 未知 | Recall 的量级无法预估，可能使 HitRate 的相对重要性进一步上升 | 以 HitRate 为主要优化目标，Recall 作为同向指标监控 |
| 新书池中 2026 年入藏的书可能过新 | 推荐了尚无人借的书，浪费推荐位 | 按入藏时间分桶，用回测选择新书权重与时间窗 |
| 老人中位数仅 4 册历史 | 共现信号薄弱，半数老人实际近似冷启动 | 对历史数 <3 的老人启用「老人 + 分群热门」混合 |
| 回测与真实验证集存在分布差异 | 调参可能过拟合到回测构造方式 | 构造两种切分点（2024-03-01 / 2024-09-01）交叉验证结论稳定性 |
